# Aşama 2 — Akıllı bildirimler: yükleme

1. GitHub'da repo ana sayfası → Add file → Upload files.
2. Bu klasörün İÇİNDEKİLERİ (api, app, assets, capacitor-app, database, includes klasörleri ve kökteki .php/.js/.json dosyaları) sürükleyip bırak → Commit changes.
3. Veritabanı değişiklikleri Supabase'e zaten uygulandı.
4. Commit sonrası GitHub Actions yeni APK'yı derler (Actions sekmesi, ~5-8 dk).
   Bitince telefondan "Android Uygulaması" sayfasından yeni APK'yı indirip kur (eskisinin üzerine).
5. Uygulamayı aç → Daha → Bildirimler sayfasında ayarları kontrol et → Kaydet.
